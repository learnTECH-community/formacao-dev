# Quem contribuiu

Aqui fica cada pessoa que ajudou a formacao-dev. Código conta, e também conta o que não é código: revisar, responder uma dúvida, testar com leitor de tela, escrever documentação, relatar um defeito, trazer uma ideia ou traduzir.

Ninguém precisa pedir para entrar. Quem mantém o projeto acrescenta a pessoa quando a contribuição é aceita.

## Os tipos

| Tipo | Conta quando |
|---|---|
| Código | um PR que muda código é mesclado |
| Documentação | um PR em `docs/`, no README ou no CONTRIBUTING é mesclado |
| Revisão | a pessoa revisa o PR de outra pessoa, com pergunta, sugestão e reconhecimento ([como revisar](../../CONTRIBUTING.md#revisão)) |
| Dúvida respondida | a resposta dela é marcada como aceita na categoria Dúvidas das [Discussions](https://github.com/learnTECH-community/formacao-dev/discussions) |
| Acessibilidade | a pessoa testa com leitor de tela ou corrige um problema de acessibilidade |
| Defeito | a issue de defeito que ela abriu é reproduzida e aceita |
| Ideia | uma ideia dela nas Discussions vira issue |
| Tradução | uma tradução de documentação dela é mesclada |

## Por que esta página existe

- Reconhecer o que não é código dá um motivo para a pessoa voltar. Comunidades grandes contam revisão, tradução e escrita, e não só o PR de código. O benchmark está em [benchmark.md](benchmark.md), na prática 5.
- O padrão vem da especificação [All Contributors](https://allcontributors.org/), conferida em 24/11/2026. Usamos a ideia, não a marca nem os emojis. Os tipos são nossos, em português, e só com o que acontece aqui.
- O painel conta só os itens do catálogo feitos em PR. Sem esta página, quem revisa, responde dúvida ou testa acessibilidade some.
